## 全部技术裁决

下列裁决按作出顺序记录；每条明确错误判断的代价。没有遗漏的 Minor 延后项。

1. 保留石墨灰／薄荷色四区域工作台，旧架构页使用显式入口。理由：围绕源代码、数据、局部运算和探针组织科研任务。代价：方向不合适时需要重新整理视觉与区域布局。
2. 保留既有 `npm test` 浏览器入口，增加 `test:e2e` 别名和 `test:unit`。理由：避免改变原有验收命令的含义。代价：需要维护和解释多个测试命令。
3. 共用测试服务时显式选择夹具示例。理由：示例选择不能依赖其他用例遗留状态。代价：夹具变化时同步更新选择与断言。
4. 模型与解释服务采用异步接口。理由：慢模型不能阻塞数据交互。代价：调用者必须 await 或显式桥接事件循环。
5. 共享命令分发器采用异步接口。理由：终端与 HTTP 共用取消和调用语义。代价：同步调用者需要桥接事件循环。
6. 分开提供终端 `/explain` 与批处理研究解释命令。理由：兼顾交互上下文与脚本使用。代价：维护两个客户端命令入口。
7. Web 脚本参数使用 JSON 数组。理由：准确保留空字符串、引号和含空格参数。代价：用户需了解这一小段格式。
8. Windows 桌面使用 Electron 替代原建议 Tauri。理由：当前机器没有 Rust/MSVC；私有 Chromium 壳可直接安装与验收。代价：安装包和 Chromium 内存更大；壳可独立替换。
9. Windows Store Python 拒绝嵌套 Job 时，保留已认证服务进程句柄用于超时终止。理由：虚拟环境启动器 PID 不等于服务 PID，不重新打开可能复用的 PID。代价：强行结束拥有者时需要租约完成有界回收。
10. 桌面以固定 PowerShell 文件和结构化参数打开终端。理由：安装包没有全局 CLI PATH，用户需要可发现的终端入口。代价：额外维护这一小型 Windows 客户端动作，其他桌面平台未验证。
11. Electron 使用原生 Playwright `.cjs` 和私有 Chromium 验收。理由：实际验证所选壳及已安装程序。代价：不验证 Tauri/WebView2。
12. SSE 空轮询由 100ms 改为 50ms，十秒心跳保持。理由：真实流式 p95 超出预算。代价：活跃空闲订阅者的轻量 SQLite 轮询频率翻倍，结束后仍关闭流。
13. 本轮不判断真实付费模型质量、计费和真实凭据连通性。理由：未获真实调用／付费授权，使用本地合成协议服务和离线规则。代价：用户首次接入实际供应商时还需验证服务与模型。
14. 本轮不判断 macOS/Linux 原生安装包与窗口生命周期。理由：原生首版交付 Windows，跨平台 Python 核心仍须通过 CI。代价：其他平台的桌面壳不能作为已验收发行物。
15. 本轮不保证外部适配器、探针及渲染器实现内部正确。理由：验证了公开扩展协议和独立点云示例，外部插件源码未提供。代价：实际插件需自行进行兼容、预算和数据正确性测试。
16. 不将旧架构页视为无限期科研实时运行界面。理由：科研默认页有有界缓存与实测，旧页完整事件数组没有长期量化证据。代价：长期使用旧页可能持续占用内存，应使用科研页或分段历史查看。
17. POSIX 忽略 SIGTERM 的用户子进程，以及并发 SDK 全量采集额度的极端组合仍未取得本轮独立复现。理由：审查不对未完成验证的边界给通过结论。代价：这些特殊脚本需额外验证终止和产物上限；一般取消／进程错误路径已有回归。
18. 生成产物与供应商内部实现未逐行完整审计。理由：独立审查侧重首方源码，并执行构建 UI；安全扫描明确保留生成／供应商排除。代价：不构成完整供应链安全保证。
