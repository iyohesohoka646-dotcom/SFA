## 本轮修复的实际故障

静态解析重复切分整份源码导致千级对象开销过高，已改为缓存 UTF-8 行切片。原有图边命中区域会挡住节点，已移除边的交互命中区域。数据详情的布局覆盖了切片控件，已调整滚动和最小高度。更换源文件会保留旧运行范围，已切换到新定义。用户保存关系图设置会覆盖已配置的采集与智能预算，已限定设置更新范围。

原生终端新会话没有继承无障碍输出设置，已修复。历史输出中的设备查询会在重连时重复作答，把转义字符送进 Python 输入，已区分重放与实时输出并抑制历史查询响应。Windows 并发解析重复替换归档文件引发拒绝访问，已改为在项目存储锁下写入一次，冲突证据保持原状并报错。

浏览器关闭时的页面离开请求偶尔未送达，或留下未完成的连接租约，使服务继续停留到首次启动超时。已改为最后一个实际连接断开后进入刷新宽限；刷新重连可继续使用，关闭最后标签后拥有的服务及时停止。独立 CLI 计算与借用的服务保留原有生命周期。

新运行尚未出现在历史列表时，下拉框会显示空白，现保留当前运行的明确选项。关系图切换结构／数据视图或进入块时会重新适应该范围，选中、虚化、数值更新和查看固定历史图仍保持相机；布局耗时在本次布局完成后更新。

旧包元数据和旧构建目录可能使验收误选 0.4 或带入废弃前端资源。构建和验收脚本现固定当前发行名，核对 wheel 与当前静态资源集合，并逐字节核对私有桌面运行时。
