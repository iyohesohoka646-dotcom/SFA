# 科研工作台 0.4

打开 `.py` 文件后点击“导入解析”。此时只读取源码和安装包元数据，不执行实验，也不绘图。在“探针台”选择呈现、检查或解读方式并绑定对象；点击“运行”才创建不可变计划，执行计算，再生成有预算的结果。菜单“仅执行探针”“仅重绘”使用已保存证据，保持原运行 ID。计算结果与探针质量分别显示，绘图失败不会抹去完成的计算。

标签拖入另一分屏可调整位置，双击固定文档；“并排固定此版本”保留不可变数据版本用于比较。分隔线支持鼠标和方向键，视图顶部可缩小、还原、全屏、关闭。“布局”可增加横纵分屏、合并空槽、保存和恢复命名方案。“锁定布局”固定各槽尺寸，保留空槽及新标签的指定工作区。解锁后调整。窄屏按当前工具显示单文档，导航保留所有入口。

“计算关系图”单独缩放、搜索、展开分组和拖动节点；点击对象后直接输入呈绿色、直接下游呈蓝色，未关联对象淡化。实线为运行观察、虚线为源码推断，关系探针返回同一份直接关系证据。图中位置不修改源码。当前关系浏览器有界显示，未实现任意连线直接改写程序语义。

探针有三种能力：**view** 呈现数据（矩阵、表、标量、关系、绘图库），**check** 判断数据（数值、形状、自定义程序、人工），**interpret** 解释证据（模型、Skill）。执行方式单独记录。程序检查使用独立进程；模型或 Skill 解读保留来源，不能当作确定性自动检查。纯数据、热图等内置视图读取保存样例；完整数据未采集时明确显示精度与可用范围。

“工具库”的公开目录不依赖用户现有安装。扫描所选解释器的 distribution 元数据，无导入绘图库副作用。已适配 Matplotlib / Seaborn / Plotly / Altair；Bokeh / PyVista / HoloViews 仅列为候选。安装、停用、移除发生在 `.cdaf/research/drawing-env` 管理环境，具体位置以任务回执为准，不修改计算解释器。图形产物保留工具版本、数据版本与摘要缓存。PNG、Plotly HTML、Vega-Lite JSON 可随脱敏报告离线打开，嵌入预算为 16 MiB。

“模型设置”与 CLI `/model`、`cdaf models` 共用凭据和配置。智能助手按解析、解释、探针、代码四个角色配置模型、输入输出预算、工具次数与执行权限。上下文自动包含环境、注册工具、对象索引、焦点、直接关系和任务约束；数据样例默认不发送。调用记录可展开查看实际消息、工具参数、工具结果、引用和用量。代码角色只能提案，不能接受补丁；开启执行权限才允许工作台执行工具。外部代理的文件或网络权限不由此工作台代管。

“代码审查”比较指定对象的源码片段。函数修改保留签名和装饰器，稳定赋值保持目标，新增分析文件限制在项目目录；语法、符号、顶层结构、内嵌 import 和原始源码摘要会阻断违规或过期补丁。结构有效仍标注行为未验证；真实运行与程序检查可附为验证证据。回滚生成新的审查提案，仅支持可保真保存的原始片段。工具不会自动执行新代码。

`workbench.yaml` 保存可提交的配置；`research.yaml`、v1 运行 ID 和证据保留兼容。`cdaf research migrate-config` 先预览，`--apply` 创建字节保真的备份且拒绝覆盖现有新版配置。CLI 任务默认等待结束，Ctrl+C 取消自己启动的任务；交互 `/workbench COMMAND JSON` 和网页命令台使用同一命令适配层。
