# 科研工作台 0.5

导入单个 Python 文件后“导入解析”，对象浏览器和计算关系图来自该源码版本。导入、选择、探针配置和模型配置都不运行实验。顶部“运行模式”选择计算与探针、仅探针或仅重绘，再按“运行”执行；当前选择、当前块、整个项目是三个独立范围。

对象浏览器按目录、文件、函数与源码顺序组织，条件和循环在计算图中查看。当前最大层级展开，其下默认折叠。同作用域的重复赋值合并为一行，优先显示最后实际观测的值；未执行分支不冒充最终结果。展开变量可查看静态定义和运行历史，选中会高亮同作用域的定义与使用；遮蔽变量分别管理。单击只选中，Ctrl/Cmd 增减选项，Shift 连续选择，Ctrl/Cmd+A 选择全部匹配项，双击或 Enter 打开证据。右键提供打开数据、定位源码、进入块与绑定探针；进入范围同步树、探针和结果，选择不导航。目录层目前来自单文件路径，文件夹导入由后续块提供器扩展。

计算关系图的“结构”视图显示函数、条件、循环底板及计算单元，省去独立值节点；“数据”显示变量、参数及已观测的类型与形状；“执行”叠加真实路径、状态和计数，无证据的关系保留未观测状态。最大块展开、后代结构块默认折叠，折叠关系保留带条件或变量名称的独立端点。颜色、类型标识和线形区分对象、数据、控制、调用及回边。默认保留完整背景，淡化可关闭。空白处左键或中键拖动画布，框选模式及 Shift 用于选择；单击不移动相机。浮动“布局与关系”面板提供筛选、方向和层级操作。ELK Worker 使用真实尺寸、嵌套端口和路由，长链自动换行；选择和数值更新不重新布局。右键可固定位置，整理保留固定项。循环计数指循环体进入次数，强制中止显示不完整下界。

探针库管理资源，探针台管理绑定，两者独立。先按作用对象浏览，再按呈现、检验、解释、推导及实现方式筛选。公开目录与本机安装状态分开；Matplotlib、Seaborn、Plotly、Altair 已适配，其余候选显示真实支持状态。第三方入口的启用会校验项目解释器中的依赖、源码摘要和审查版本；声明导入保持草案状态。绘图库方法、签名与文档元数据可以显式检测，AI 可以提出适配草案，启用仍需审查。

新项目可见的自动呈现探针提供基础图形。数据面板始终显示名称、类型、形状和来源，图形与表格由有效探针决定。停用、删除和对象停用例外持久保存，关闭标签不删除探针；“恢复项目默认”是明确操作。多个呈现探针可固定为独立视图。隐藏数据视图停止绘制，第三方绘图和模型推理需要执行动作。

呈现设置支持数值覆盖、精度、矩阵色阶和数据语义。轴名称、坐标、单位、行列标签与元素定义必须匹配维度；表格可标注列含义。配置可保存为模板。热图显示真实色阶端点、恒定值与缺失图例，选中单元显示精确数值；抽样明确限定覆盖范围。

多选后可绑定并排比较、关系分析或推导探针，并通过输入角色明确参数顺序。推导包括逐元素运算、矩阵乘法、聚合、相关与按键表格连接。默认同次运行、严格形状匹配，广播与跨运行输入需明确开启。完整数据缺失、坐标不匹配和预算不足会形成诊断；补采集创建新运行。派生对象保存不可变父引用，可继续绑定探针、保留或生成供审查的代码提案。

派生结果继续保存存活轴的坐标和来源：逐元素运算保留一致坐标，矩阵乘法保留外轴，聚合移除被聚合轴。无法确认的坐标保留明确缺口；默认联合运算会阻断，用户可以补充定义或显式选择按位置计算。每次冻结计划和读取完整输入时都会重新核对当前形状，旧版本的坐标长度不匹配时不能继续计算。

标签可拖放到横纵分屏，双击固定文档；缩小释放空间并保留恢复入口，放大后恢复原位置。命名布局可保存，锁定时保留槽位和尺寸，仍可切换、查看和临时放大。900–1600 像素布局保持可调整，极窄窗口聚焦单组。“设置”集中管理工作区、图、默认探针、采集、模型、扩展环境、终端、存储与版本；用户默认、项目覆盖和实例参数分别显示来源。

任务按运行、阶段与探针调用组织；结果按目标、探针、状态筛选；事件支持范围与类型筛选，重复控制默认聚合。执行状态、检查结果、采集完整性各自保留。历史图绑定当时的源码，迟到结果不会改变新选择。

Web 与 Windows 桌面的终端使用真实 PTY，可创建应用 CLI、Python 和 Shell 会话。隐藏或缩小保留会话，结束会话终止进程；拥有服务的窗口退出会清理所属进程。中文、Ctrl+C、尺寸同步和重连均使用同一终端服务。会话输出有界且默认不进入模型上下文。

智能助手按任务自动构建有预算的环境、工具、对象与证据上下文。显示关系不扩大读取权限；数据样例默认不发送，调用、引用与用量可查看。模型探针从已保存的服务及模型中选择，任务、重点、约束和输出要求分别保存并进入实际请求。探针台先显示所选对象已有的继承及本地绑定，再设置新探针；“当前块”未进入范围时指当前文件。探针库默认参数只供新绑定复制，修改后不会改写已有绑定。

智能助手的“整理代码书写”使用已配置模型读取当前完整文件，提出分行、缩进、间距及段落整理。候选必须保持计算语法树、声明、语句顺序、注释和类型忽略所属语句，并且可用原编码写回。查看差异后才能接受；回滚也需接受提案。当前上限为 16384 字符，含明文凭据的源码不能发送。行号可能变化；涉及源码位置或自检源码的程序仍需实际验证。整理不替代图布局，计算语义不由绘图或模型意见决定。普通代码修改仍以局部候选审查；任何提案应用后都需明确运行。
