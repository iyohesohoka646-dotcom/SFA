# 科研工作台 0.5

导入单个 Python 文件后“导入解析”，对象浏览器和计算关系图来自该源码版本。导入、选择、探针配置和模型配置都不运行实验。顶部“运行模式”选择计算与探针、仅探针或仅重绘，再按“运行”执行。新探针和模板作用于当前选择或整个项目；文件、函数或控制块可以直接作为选择范围。

对象浏览器按目录、文件、函数与源码顺序组织；每个逻辑变量只占一行，后面只显示类型、形状和启用探针数量。同作用域的重复赋值合并，数据页默认打开最近实际捕获的值；“版本”查看先前结果，未执行分支不充当最终值。类型筛选为“仅变量／全部”，探针结果筛选为“全部／探针异常／正常”；没有结果的对象不会被算作正常。当前最大层级展开，其下默认折叠，搜索可展开匹配路径。选中会高亮同作用域的全部定义与使用，遮蔽变量分别管理。单击只选中，Ctrl/Cmd 增减选项，Shift 连续选择，Ctrl/Cmd+A 选择全部匹配项，双击或 Enter 打开证据。右键提供打开数据、定位源码、进入块与绑定探针；进入范围同步树、探针和结果，选择不导航。目录层目前来自单文件路径，文件夹导入由后续块提供器扩展。

计算关系图只保留 **Code／Data** 两种模式，画布上的按钮和标签使用英文。Code 显示函数、条件、循环底板及实际计算依赖。判断和循环用圆形，计算用菱形并显示短表达式；跨块数据依赖和条件控制保持连接，互不依赖的调用不添加逐行顺序箭头。长标签自动换行。省去独立变量、文档字符串、入口出口和合流辅助节点。Data 只显示逻辑变量及其依赖，同作用域的多个版本合并，运算路径转成变量关系；依赖仍可追溯到原图。最大块展开，后代结构块默认折叠。类型以颜色、形状和图标区分；条件标在端口旁，普通线不重复加标签。完整源码通过右键 Source 或 Details 打开。进入块后用 Back 返回上一级、Root 返回总览。默认保留完整背景；Options 中可选择关系类别、淡化背景、方向和层级，以及显式叠加已保存运行证据，不再为每个节点添加“未观测”。

Move canvas 在空白处拖动画布，Box select 在空白处框选；Space 临时平移，Shift 临时框选。两种模式均可拖动节点，展开块通过标题栏移动；单击不移动相机。Arrange 使用 ELK Worker 的分层排列、统一单元宽度、专用连线间距和正交路由；依赖链按方向连续排列，避免强行折行产生长折返线。选择、淡化和数值变化不触发布局。右键 Pin position 固定位置，Arrange 保留固定项；Options 中重置位置可整理全部。纵向嵌套循环使用同一布局协议。循环计数指循环体进入次数，强制中止显示不完整下界。

探针库管理资源，探针台管理绑定，两者独立。先按作用对象浏览，再按呈现、检验、解释、推导及实现方式筛选。公开目录与本机安装状态分开；Matplotlib、Seaborn、Plotly、Altair 已适配，其余候选显示真实支持状态。第三方入口的启用会校验项目解释器中的依赖、源码摘要和审查版本；声明导入保持草案状态。绘图库方法、签名与文档元数据可以显式检测，AI 可以提出适配草案，启用仍需审查。

新项目应用可管理的“自动数据视图”探针模板，其成员提供自适应基础图形。数据面板按有效探针逐项呈现，每个成员有独立可折叠区域和设置，可以固定为独立标签；不再提供重复的全部／自动选择器。没有有效探针时，只保留变量名和“打开探针台”。统计和采集信息属于具体呈现探针，外部不重复添加。检验与解释结果也按绑定分别列出。停用、删除和对象停用例外持久保存，关闭标签不删除探针；“恢复项目默认”是明确操作。收起呈现区域或隐藏数据视图会停止昂贵绘制；第三方绘图和模型推理需要明确执行，修改参数后的旧产物不能冒充新结果。普通数组的数值表使用真实抽样行列坐标，表格保留独立的行号与索引标签。

呈现设置支持数值覆盖、精度、矩阵色阶和数据语义。轴名称、坐标、单位、行列标签与元素定义必须匹配维度；表格可标注列含义。配置可保存为模板。热图显示真实色阶端点、恒定值与缺失图例，选中单元显示精确数值；抽样明确限定覆盖范围。

多选后可绑定并排比较、关系分析或推导探针，并通过输入角色明确参数顺序。推导包括逐元素运算、矩阵乘法、聚合、相关与按键表格连接。默认同次运行、严格形状匹配，广播与跨运行输入需明确开启。完整数据缺失、坐标不匹配和预算不足会形成诊断；补采集创建新运行。派生对象保存不可变父引用，可继续绑定探针、保留或生成供审查的代码提案。

派生结果继续保存存活轴的坐标和来源：逐元素运算保留一致坐标，矩阵乘法保留外轴，聚合移除被聚合轴。无法确认的坐标保留明确缺口；默认联合运算会阻断，用户可以补充定义或显式选择按位置计算。每次冻结计划和读取完整输入时都会重新核对当前形状，旧版本的坐标长度不匹配时不能继续计算。

标签可拖放到横纵分屏，双击固定文档；缩小释放空间并保留恢复入口，放大后恢复原位置。命名布局可保存，锁定时保留槽位和尺寸，仍可切换、查看和临时放大。900–1600 像素布局保持可调整，极窄窗口聚焦单组。“设置”集中管理工作区、图、默认探针、采集、模型、扩展环境、终端、存储与版本；用户默认、项目覆盖和实例参数分别显示来源。

任务按运行、阶段与探针调用组织；结果按目标、探针、状态筛选；事件支持范围与类型筛选，重复控制默认聚合。执行状态、检查结果、采集完整性各自保留。历史图绑定当时的源码，迟到结果不会改变新选择。

Web 与 Windows 桌面的终端使用真实 PTY，可创建应用 CLI、Python 和 Shell 会话。隐藏或缩小保留会话，结束会话终止进程；拥有服务的窗口退出会清理所属进程。中文、Ctrl+C、尺寸同步和重连均使用同一终端服务。会话输出有界且默认不进入模型上下文。

智能助手按任务自动构建有预算的环境、工具、对象与证据上下文。显示关系不扩大读取权限；数据样例默认不发送，调用、引用与用量可查看。模型探针从已保存的服务及模型中选择，任务、重点、约束和输出要求分别保存并进入实际请求。探针台通过“选中对象、新探针、应用模板”切换；选中对象按可折叠列表显示已有绑定。新探针与模板分别应用到当前选择或整个项目；选择文件、函数或控制块即可指定块目标。模板在探针库创建和配置，应用时复制成员参数并记录来源；之后修改模板不会改写旧绑定。旧单探针参数记录保留为参数预设。探针库默认参数只供新绑定复制，修改后不会改写已有绑定。

智能助手的“整理代码书写”使用已配置模型读取当前完整文件，提出分行、缩进、间距及段落整理。候选必须保持计算语法树、声明、语句顺序、注释和类型忽略所属语句，并且可用原编码写回。查看差异后才能接受；回滚也需接受提案。当前上限为 16384 字符，含明文凭据的源码不能发送。行号可能变化；涉及源码位置或自检源码的程序仍需实际验证。整理不替代图布局，计算语义不由绘图或模型意见决定。普通代码修改仍以局部候选审查；任何提案应用后都需明确运行。
