# 能力与覆盖边界

当前候选版本面向本地科研代码理解。事件来自实际运行，源码推断关系单独标记。形状可以确认为 `120×8`，没有用户注释时实验意义保持未知。规则模板解释已知运算，模型解释需要核对。

| 范围 | 已实现 | 当前边界 |
| --- | --- | --- |
| 数据 | Python 标量、NumPy 数值、pandas 表格、独立点云示例 | GPU、稀疏、延迟、分布式类型需要显式适配器 |
| 运算 | 赋值、解包、循环、分支、函数作用域、可识别原位写入 | 反射、生成代码、异步／生成器内部、隐藏原生写入有覆盖诊断 |
| 版本 | 小预览观察时复制；完整历史按指定产物读取 | 未保存或过期不可切片，不能以最新值代替 |
| 探针 | 数值、形状、类型、范围等；显式昂贵检查 | 抽样通过只覆盖样本，缺数据返回 unknown/skipped |
| 界面 | 四区域、局部图、切片、时间线、解释、脱敏离线 HTML | 新渲染器须重新构建，不执行网络插件脚本 |
| 模型 | OpenAI-compatible、Anthropic、离线规则、引用与取消 | 假服务测试不证明外部模型、计费或解释质量 |
| 部署 | 本地 Web、Windows 桌面、交互 CLI 和批处理 | 无多租户、协作、分布式调度；其他桌面平台未验收 |

默认最多 80 个可见节点，矩阵预览 1024 个单元、统计 4096 个元素，完整切片 4096 个单元。高频普通观察可合并，丢弃、截断和采集故障有记录。程序正常返回不能代表科学数值可靠。

代码和显式插件保留用户的文件／网络权限。适配器在分析进程中运行，探针在独立进程运行。详见 [instrumentation.md](instrumentation.md)、[adapter-api.md](adapter-api.md)、[probe-api.md](probe-api.md)。

性能仅覆盖记录中的机器、数据、采集档位和观察范围。十分钟运行不证明无限期稳定或任意大数据低开销。完整采集显著增加耗时与磁盘，应按需要开启。
